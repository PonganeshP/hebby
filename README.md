# Hebby

A friendly animal buddy (Elephant, Fox or Rabbit) that lives in your VS Code status bar and nudges you to look after yourself while you code.

## What it does

- Greets you every time VS Code starts.
- Reminders in a repeating cycle: water (30 min) -> mini break (+30 min) -> walk (+60 min).
- Answer **Yes**, **Skip** or **Remind me later** (snoozes 20 min).
- Click the status bar buddy to enable/disable, change avatar, or rename.

## Settings

`hebby.waterAfterMinutes`, `hebby.miniBreakAfterMinutes`, `hebby.walkAfterMinutes`, `hebby.snoozeMinutes`.
